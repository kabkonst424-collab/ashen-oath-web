# Пепельная клятва — веб-демо (актуальная версия)

Браузерная сборка демо первого акта «Пепельной клятвы» (Ashen Oath).
Репозиторий используется как источник для кнопки «Играть» на сайте
https://theforgeforall.ru — сайт открывает именно эту версию.

## Адрес

    https://kabkonst424-collab.github.io/ashen-oath-web/

## Структура

Игра лежит в корне репозитория: `index.html`, `src/`, `assets/`.
`.nojekyll` отключает обработку GitHub Pages через Jekyll, чтобы все файлы
отдавались без изменений.

## Обновление версии

1. Замените файлы в корне новой сборкой.
2. GitHub Desktop → Commit → Push.
3. Если путь `index.html` не менялся, ссылка на сайте продолжит работать.
