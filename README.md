# Пепельная клятва · Кампания 1.0.0

Пошаговая ролевая игра с отрядом. Шесть актов, девятнадцать областей и два финала.
Алар, Мирт и Элиан начинают в одной точке истории со своими умениями, снаряжением и характеристиками.
У каждого героя отряда две ветки развития. Руны меняют свойства боевых навыков.

## Играть

[Открыть кампанию в браузере](https://kabkonst424-collab.github.io/ashen-oath-web/index.html?v=1.0.0)

Сохранения первого акта продолжаются в кампании. При переносе между браузерами воспользуйтесь экспортом и импортом в меню «Сохранения и восстановление». Сюжет продолжается по северному тракту из аббатства.

## Файлы игры

Точка входа `index.html` расположена в корне. Код кампании лежит в `src/act1/`, новые модели, комиксы и звук — в `assets/campaign/`. Новые модели и звуковые темы загружаются по мере прохождения. `build-manifest.json` содержит размеры и контрольные суммы файлов выпуска.
