Исходная сборка Web 1.8.0, коммит `2bfb2fea9822bb2f16dc258a10567fe1ad1eb802`.

## Внедрение и проверка

1. Сделан лист ключевых поз ImageGen с мечом, луком и посохом. Лист помещён в сцену Blender рядом с редактируемыми кривыми.
2. Blender запёк 13 кривых по 25 отсчётов. `tools/bake_reference_curves.py` восстанавливает `src/act1/reference-curves.js`. Кривые запаздывания, разгона и возврата используются в библиотеке анимаций и в контроллере лука. Исходные клипы и модели проверяются по прежним контрольным суммам.
3. Для 798 клипов из 82 файлов профилей проверены фактические изменения, длительности, ключи опоры, выпуск, контакт и удержание конечной позы. Смещение в отдельном ключе ограничено 13° для действий стоя и 16° для падения. Эти пределы относятся к разнице поз в проекте.

Оценка по видеокадрам разделяет совпадение опорных фаз и художественное сходство полных движений. Число изменённых клипов и точность игровых ключей измеримы. Для 90% сходства каждой полной анимации с внешними видео потребовалась бы сопоставимая разметка траекторий обоих ригов.
