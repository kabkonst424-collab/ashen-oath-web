# Источник движений отряда

Данные захвата движения получены из [CMU Graphics Lab Motion Capture Database](https://mocap.cs.cmu.edu/). База создана при поддержке NSF EIA-0196217.

Для ходьбы использованы записи [35_02](https://mocap.cs.cmu.edu/subjects/35/35_02.amc) и [35_03](https://mocap.cs.cmu.edu/subjects/35/35_03.amc), для бега — [35_17](https://mocap.cs.cmu.edu/subjects/35/35_17.amc) и [35_18](https://mocap.cs.cmu.edu/subjects/35/35_18.amc). Два игровых цикла адаптированы к пропорциям персонажей и скорости движения, с отдельной подстройкой опоры под поверхность.
